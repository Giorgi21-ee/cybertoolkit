02 / ABOUT

Small tools, real concepts

Cyber Lab is an independent educational toolkit for exploring networking, encoding and cryptography. It is designed for learning, not production security assessments. No analytics or application-side data collection is included.

SHA-256 is a hash, not encryption. Base64 is an encoding, not a security mechanism.
